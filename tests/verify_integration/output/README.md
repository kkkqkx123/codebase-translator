# Verify Integration Tests Output

This directory contains the output files generated by the verify integration tests.

## Test Files

### Fixtures
- `simple_rust.rs` - Simple Rust file with basic patterns (comments, strings, docstrings)
- `complex_rust.rs` - Complex Rust file with various patterns including error messages, log messages, format strings, and special characters

### Output Files

#### Simple Rust File Tests
- `simple_rust_verification.txt` - Table format output with detailed information
- `simple_rust_classification.txt` - Pattern classification output
- `simple_rust_categories.json` - Category distribution in JSON format
- `simple_rust_positions.txt` - Position tracking output

#### Complex Rust File Tests
- `complex_rust_verification.txt` - Table format output with detailed information
- `complex_rust_verification.json` - JSON format output
- `complex_rust_verification.csv` - CSV format output

## How to Generate Output

Run the end-to-end tests to generate output files:

```bash
cargo test --test verify_integration_tests test_end_to_end -- --nocapture
```

## Understanding the Output

### Table Format
Shows matches in a formatted table with columns:
- Pattern: The pattern name (e.g., comment, string_literal, docstring)
- Type: Pattern type (Builtin, CustomRegex, StateMachine)
- Category: Pattern category (other, variables, output, etc.)
- File: Source file name
- Line: Line number
- Extracted Text: The extracted text content
- Raw Match: The raw match from the source file

### JSON Format
Structured JSON output containing:
- Matches array with detailed match information
- Summary statistics

### CSV Format
Comma-separated values for easy import into spreadsheet applications

## Test Coverage

The integration tests cover:
- Pattern extraction and classification
- Multiple output formats (Table, JSON, CSV)
- Position tracking
- Category distribution
- Special characters handling
- Long text truncation
- Empty matches handling
- Statistics generation

## Viewing Results

Open any of the output files in a text editor to view the verification results. The table format is most readable for human inspection, while JSON and CSV formats are better for programmatic processing.
