## 一、当前实现概述

### 1.1 架构设计

Parser模块采用**注册表模式**，支持多语言解析器的动态注册和获取：

```
Parser接口
    ↓
Registry (注册表)
    ↓
具体实现
    ├── GoParser (已实现)
    ├── PythonParser (待实现)
    ├── JavaScriptParser (待实现)
    └── ...
```

### 1.2 核心接口

```go
type Parser interface {
    Parse(ctx context.Context, file *domain.File) ([]domain.TranslationUnit, error)
    Supports(filename string) bool
}
```

**职责说明：**
- `Parse`: 解析文件，提取可翻译的文本单元
- `Supports`: 判断是否支持特定文件类型

### 1.3 配置结构

```go
type ParserConfig struct {
    SourceLang string // 源语言
    TargetLang string // 目标语言
}
```

## 二、GoParser 详细分析

### 2.1 技术实现

**核心技术：Go AST（抽象语法树）**

使用标准库 `go/ast` 和 `go/parser` 进行语法分析：

```go
fset := token.NewFileSet()
node, err := parser.ParseFile(fset, file.Path, nil, parser.ParseComments)

ast.Inspect(node, func(n ast.Node) bool {
    switch x := n.(type) {
    case *ast.CommentGroup:  // 提取注释
    case *ast.CallExpr:      // 提取错误消息
    }
    return true
})
```

### 2.2 提取的内容类型

| 类型 | 识别方式 | 示例 |
|------|---------|------|
| **单行注释** | `//` 开头 | `// 这是一个中文注释` |
| **多行注释** | `/* */` 包裹 | `/* 这是多行注释 */` |
| **文档注释** | 注释内容包含特定关键词 | `// Package xxx ...` |
| **错误消息** | 特定函数调用的字符串参数 | `errors.New("操作失败")` |

### 2.3 提取的位置信息

每个提取的文本单元都记录精确位置：

```go
type TranslationUnit struct {
    ID        string
    Type      UnitType       // comment/docstring/error_message
    Content   string
    StartPos  Position       // 行号、列号、偏移量
    EndPos    Position
    Language  string         // ZH/EN/AUTO
    ShouldTranslate bool
}
```

**位置信息的作用：**
- 精确定位原文在文件中的位置
- 支持精确替换，不破坏代码结构
- 用于调试和追踪翻译单元

### 2.4 语言检测机制

#### 检测逻辑

```go
func (p *GoParser) detectLanguage(text string) string {
    // 1. 优先使用配置的语言
    if p.config.SourceLang != "" && p.config.SourceLang != "AUTO" {
        return p.config.SourceLang
    }

    // 2. 检测CJK字符（中日韩）
    if p.containsCJK(text) {
        return "ZH"
    }

    // 3. 检测拉丁字母
    if p.containsLatin(text) {
        return "EN"
    }

    return "AUTO"
}
```

#### CJK字符检测范围

- **汉字**: Unicode `Han` 区块
- **平假名**: Unicode `Hiragana` 区块
- **片假名**: Unicode `Katakana` 区块
- **韩文**: Unicode 范围 `0xAC00-0xD7A3`

#### 拉丁字母检测

统计拉丁字母占比，超过50%判定为英文。

### 2.5 过滤规则

**自动排除以下内容：**

| 排除类型 | 规则 | 示例 |
|---------|------|------|
| **开发标记** | TODO/FIXME/NOTE | `// TODO: implement this` |
| **URL** | 包含 http:// 或 https:// | `// See https://example.com` |
| **Email** | 包含 @ 符号 | `// Contact user@example.com` |
| **版权信息** | Copyright/License | `// Copyright 2024` |
| **作者信息** | Author | `// Author: John Doe` |

**过滤的作用：**
- 避免翻译不需要的内容
- 节省翻译API调用成本
- 保持版权和法律文本不变

### 2.6 错误函数识别

**当前识别的错误函数：**

```go
errorFunctions := map[string]bool{
    "fmt.Errorf":     true,
    "errors.New":     true,
    "log.Fatal":      true,
    "log.Panic":      true,
    "panic":          true,
    "logger.Error":   true,
    "logger.Fatal":   true,
    "logger.Panic":   true,
}
```

**识别逻辑：**
- 解析函数调用表达式
- 检查函数名是否在白名单中
- 提取字符串字面量参数
- 判断字符串内容是否需要翻译

### 2.7 注释类型判断

```go
func (p *GoParser) determineCommentType(text string) domain.UnitType {
    if strings.HasPrefix(text, " ") || strings.HasPrefix(text, "\t") {
        return domain.UnitTypeComment
    }

    if strings.Contains(text, "Package ") || strings.Contains(text, "Function ") {
        return domain.UnitTypeDocString
    }

    return domain.UnitTypeComment
}
```

**类型区分：**
- **普通注释**: 缩进的注释（代码内联注释）
- **文档字符串**: 包含 "Package" 或 "Function" 等关键词

func (p *GoParser) determineCommentType(text string, comment *ast.CommentGroup, fset *token.FileSet) domain.UnitType {
    // 1. 检查是否是文档注释（在声明之前）
    pos := fset.Position(comment.Pos())
    if pos.Line == 1 {
        return domain.UnitTypeDocString // 文件头部注释
    }

    // 2. 检查注释内容格式
    if strings.HasPrefix(text, "Package ") ||
       strings.HasPrefix(text, "Function ") ||
       strings.HasPrefix(text, "Method ") ||
       strings.HasPrefix(text, "Type ") ||
       strings.HasPrefix(text, "Var ") ||
       strings.HasPrefix(text, "Const ") {
        return domain.UnitTypeDocString
    }

    // 3. 检查是否是godoc格式
    if strings.Contains(text, "// ") && 
       (strings.Contains(text, "returns") || 
        strings.Contains(text, "params") ||
        strings.Contains(text, "returns:")) {
        return domain.UnitTypeDocString
    }

    return domain.UnitTypeComment
}
```

**预期效果：**
- 更准确识别文档注释
- 支持godoc格式

func (p *GoParser) parseGenDecl(decl *ast.GenDecl, fset *token.FileSet) []domain.TranslationUnit {
    var units []domain.TranslationUnit

    for _, spec := range decl.Specs {
        if valueSpec, ok := spec.(*ast.ValueSpec); ok {
            for i, value := range valueSpec.Values {
                if lit, ok := value.(*ast.BasicLit); ok && lit.Kind == token.STRING {
                    text := strings.Trim(lit.Value, `"`)
                    
                    // 只提取看起来像可翻译文本的字符串
                    if p.shouldTranslate(text) && !p.isCodeIdentifier(text) {
                        pos := fset.Position(lit.Pos())
                        endPos := fset.Position(lit.End())
                        
                        unit := domain.TranslationUnit{
                            ID:      generateUnitID(pos.String(), text),
                            Type:    domain.UnitTypeStringLiteral,
                            Content: text,
                            StartPos: domain.Position{
                                Line:   pos.Line,
                                Column: pos.Column,
                                Offset: pos.Offset,
                            },
                            EndPos: domain.Position{
                                Line:   endPos.Line,
                                Column: endPos.Column,
                                Offset: endPos.Offset,
                            },
                            Language:       p.detectLanguage(text),
                            ShouldTranslate: true,
                        }
                        
                        units = append(units, unit)
                    }
                }
            }
        }
    }

    return units
}

// 判断是否是代码标识符（如常量名、枚举值等）
func (p *GoParser) isCodeIdentifier(text string) bool {
    // 检查是否全大写（常量命名习惯）
    if text == strings.ToUpper(text) && len(text) > 2 {
        return true
    }
    
    // 检查是否包含特殊代码模式
    codePatterns := []string{
        `^\w+_\w+$`,        // 下划线分隔
        `^[A-Z0-9_]+$`,     // 全大写加数字
        `^[a-z][a-z0-9_]+$`, // 驼峰命名
    }
    
    for _, pattern := range codePatterns {
        matched, _ := regexp.MatchString(pattern, text)
        if matched {
            return true
        }
    }
    
    return false
}
```

func (p *GoParser) parseBasicLit(lit *ast.BasicLit, fset *token.FileSet) string {
    if lit.Kind == token.STRING {
        text := lit.Value
        
        // 处理原始字符串（反引号）
        if strings.HasPrefix(text, "`") {
            rawText := text[1 : len(text)-1]
            
            // 检查是否需要翻译
            if p.shouldTranslate(rawText) {
                return rawText
            }
        } else {
            // 处理普通字符串
            text = strings.Trim(text, `"`)
            return text
        }
    }
    
    return ""
}

#### 改进6：改进过滤规则

**当前问题：**
- 过滤规则简单硬编码
- 无法自定义过滤规则
- 可能误过滤

**改进方案：**
```go
type ParserConfig struct {
    SourceLang     string
    TargetLang     string
    ErrorFunctions []string
    FilterRules    FilterRules // 可配置的过滤规则
}

type FilterRules struct {
    ExcludePatterns []string // 排除的正则表达式
    IncludePatterns []string // 包含的正则表达式
    ExcludeKeywords []string // 排除的关键词
    MinLength       int      // 最小长度
    MaxLength       int      // 最大长度
}

func (p *GoParser) shouldTranslate(text string) bool {
    // 基础检查
    if len(text) == 0 {
        return false
    }

    // 长度检查
    if p.config.FilterRules.MinLength > 0 && len(text) < p.config.FilterRules.MinLength {
        return false
    }
    if p.config.FilterRules.MaxLength > 0 && len(text) > p.config.FilterRules.MaxLength {
        return false
    }

    // 排除关键词检查
    for _, keyword := range p.config.FilterRules.ExcludeKeywords {
        if strings.Contains(text, keyword) {
            return false
        }
    }

    // 正则表达式检查
    for _, pattern := range p.config.FilterRules.ExcludePatterns {
        matched, _ := regexp.MatchString(pattern, text)
        if matched {
            return false
        }
    }

    // 包含模式检查（优先）
    if len(p.config.FilterRules.IncludePatterns) > 0 {
        included := false
        for _, pattern := range p.config.FilterRules.IncludePatterns {
            matched, _ := regexp.MatchString(pattern, text)
            if matched {
                included = true
                break
            }
        }
        if !included {
            return false
        }
    }

    return true
}
```

**预期效果：**
- 支持自定义过滤规则
- 提高过滤灵活性
- 减少误过滤
