# Cache Module Design

## 概述

Cache 模块提供翻译缓存系统，基于文件哈希实现智能增量翻译，避免重复翻译相同内容，提高 CI/CD 环境中的效率。

## 设计目的

1. **智能增量处理**：通过文件哈希机制，仅翻译修改过的文件
2. **性能优化**：减少 API 调用次数，降低翻译成本和时间
3. **CI/CD 友好**：支持自动化工作流中的缓存持久化
4. **高效率存储**：使用二进制序列化和索引机制优化存储和检索

## 核心组件

### 1. BinaryCache

**位置**：`src/cache/binary.rs`

**职责**：
- 单文件二进制缓存实现
- 使用 MessagePack 序列化存储所有缓存条目
- 包含文件头、索引区和数据区
- 支持 CRC32 校验确保数据完整性

**关键设计要点**：
- 文件头包含魔数、版本、索引偏移量和校验和
- 索引区使用哈希快速定位缓存条目
- 支持配置哈希识别缓存失效
- 项目指纹确保不同项目缓存隔离

**文件结构**：
```
[CBCACHE\x00][版本][索引偏移][索引大小][校验和]
[索引区：每个条目72字节]
[数据区：MessagePack序列化的条目]
```

### 2. DirectoryCache

**位置**：`src/cache/hierarchical.rs`

**职责**：
- 基于目录的简单缓存系统
- 在执行目录下存储缓存条目
- 提供无层次结构的缓存访问

**关键设计要点**：
- 封装 BinaryCache 的简化接口
- 仅在当前执行目录存储和检索
- 适合单项目翻译场景

### 3. CacheFactory

**位置**：`src/cache/mod.rs`

**职责**：
- 缓存实例工厂
- 根据配置创建合适的缓存实例

**设计模式**：
- 工厂模式统一缓存创建逻辑
- 支持二进制缓存和目录缓存两种模式

## 技术选型

### 序列化格式
- **MessagePack**：高效的二进制序列化格式
  - 比 JSON 更紧凑
  - 比二进制结构化格式更灵活
  - Rust 生态成熟

### 哈希算法
- **SHA-256**：文件内容哈希
  - 碰撞概率低
  - 计算速度快
- **CRC32**：文件完整性校验
  - 快速验证
  - 适合文件级校验

### 并发控制
- **RwLock**：读写锁
  - 允许多个并发读取
  - 写操作独占访问
  - 适合读多写少的缓存场景

## 关键设计要点

### 1. 缓存键设计

```rust
CacheEntry {
    file_hash: String,      // SHA-256 文件内容哈希
    config_hash: String,    // 配置哈希，配置变化时缓存失效
    timestamp: u64,         // 缓存时间戳
    units: Vec<TranslationUnit>,  // 翻译单元
}
```

### 2. 缓存失效机制

- **文件内容变化**：文件哈希变化导致缓存失效
- **配置变化**：配置哈希变化导致缓存失效
- **手动清除**：支持清除全部缓存或特定文件缓存

### 3. 存储优化

- **索引优化**：72字节的固定大小索引条目，快速定位
- **数据压缩**：可选 Brotli/flate2 压缩减少存储空间
- **延迟写入**：批量写入减少 I/O 操作

### 4. 线程安全

```rust
Arc<RwLock<BinaryCache>>  // 多线程安全访问
```

- 使用 Arc 实现多所有权
- 使用 RwLock 实现读写分离
- 支持并发读取提高性能

## 性能考量

1. **内存效率**：
   - 使用紧凑的二进制格式
   - 延迟加载缓存数据
   - 合理的索引大小（72字节/条目）

2. **I/O 效率**：
   - 单文件结构减少文件系统开销
   - 索引区快速定位
   - 批量写入优化

3. **并发性能**：
   - 读写锁支持并发读取
   - 无锁哈希查找
   - 精细化的锁粒度

## 使用示例

```rust
use codebase_translate::cache::{CacheFactory, CacheConfig};
use codebase_translate::core::models::CacheMode;

let config = CacheConfig {
    mode: CacheMode::Binary,
    enabled: true,
    max_size_mb: 100,
};

let cache = CacheFactory::create(&config, "/project/path")?;

// 检查缓存
if let Some(entry) = cache.get(&file_hash, &config_hash)? {
    // 使用缓存
}

// 保存缓存
cache.set(&cache_entry)?;
```

   - TTL 生命周期
   - 持久化策略

3. **监控和分析**：
   - 缓存命中率统计
